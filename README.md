## Requirements

- Python 3
- NumPy (Experiments 5 and 8)
- Pandas (Experiments 6–13)
- Matplotlib (Experiments 8 and 9)

Install the required libraries:

```bash
python -m pip install numpy pandas matplotlib
```

## Running a program

Open a terminal in the repository folder and run the required file. For example:

```bash
python exp-8.py
```

Replace the filename with the experiment you want to run.

**Note:** Some experiments expect CSV input files with the exact filenames specified in their programs. Experiments 8–13 use Google Colab's `files.upload()` interface to upload those CSV files. Experiment 12 creates a `generated_technical_content` folder containing generated Python and notes files. The programs are based on the corresponding experiment code in the supplied lab manual.
